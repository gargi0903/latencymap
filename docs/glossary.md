# Glossary

## Clean Technical Workspace

The chosen design feel for Latencymap. It should look focused, precise, and useful without becoming a dramatic control room or a marketing page.

## Evidence Surface

The area that appears after a test runs. It includes summary metrics, the globe or table view, share link, and same-URL history.

## Equal Evidence

The rule that the globe and table present the same probe result data. The globe explains where probes ran with honest markers; the table provides exact latency, status, colo, and timestamp values. The UI switches between these views rather than showing decorative regional coverage.

## First-Run Screen

The state before any test has run. For Latencymap, this shows the dashboard shell, URL form, concise safety copy, and the bounded-request conditions rail.

## Strong Map Area

The globe should feel important after results exist, but it must show honest probe markers rather than decorative or fake regional data.
