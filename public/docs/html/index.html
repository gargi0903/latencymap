What is Latencymap?

A portfolio project for job applications and investor demos — explained in plain language.

The idea in one sentence

Latencymap lets you type a public website or API address and see how long it takes to respond from five real regions around the world — shown in a terminal-style results table with exact numbers and a shareable link.

Latency means delay: how many milliseconds pass between asking for a page and getting the first byte back. Lower is better.

What happens when you run a test

You stay in your browser the whole time. Behind the scenes, a central server receives your URL, checks it is safe to fetch, and asks small measurement programs (called probes) in different regions to visit that URL. Each probe reports back how long it took. You get a shareable link containing the full result — no account and no database needed.

The main parts

Who is it for?

Built as a portfolio project to demonstrate full-stack engineering. The primary use case is developers checking their own public APIs. It also works for founders testing a public website before launch. It is a focused demo — one-off tests, not 24/7 monitoring.

See docs/PORTFOLIO.md in the repository for elevator pitch, live demo script, and how to present this in interviews or investor meetings.
