Getting started

Run the project on your computer even if you have never written code.

What you need installed

Node.js — a runtime that lets your computer run this project. Download it from nodejs.org if you do not have it. It includes npm, a tool for installing project dependencies and running shortcuts.

You do not need to learn JavaScript or TypeScript to follow this guide. You will copy a few terminal commands and open a web page.

Setup steps

Open a terminal in the project folder. Run each step in order. The last command starts two things: the website (port 3000) and one practice probe (port 8787).

Before step 3, create a small config file by copying the example. Inside it, set PROBE_SECRET to any password you invent (for example my-local-password). The website and probe must use the same password so they trust each other.

Try it in the browser

Go to http://localhost:3000. Type a public URL like https://example.com and click Run Test. After a few seconds you should see results in the regional table and row inspector.

On your computer there is only one practice probe, not five real world regions. The numbers are real timings, but they all come from your machine — useful for learning the tool, not for true geographic comparison.

What to learn first (in order)

What happens when you click Run Test

Your browser sends the URL to the central server running on your laptop. The server validates the link, asks the local probe to fetch it, collects timing data, and sends results back to the dashboard. A share link is built by packing the results into the URL itself.

Terminal shortcuts

These are typed in the terminal. npm install is only needed once. npm run dev:local is what you use day to day. The others are optional checks used before sharing changes with a team.
